# Object-Detection-and-Classification-of-Hyperspectral-Images-Using-KNN
Researched hyperspectral imaging and applied K-NN for object detection/classification using Salinas, PaviaU, and Indian Pines datasets. Achieved 91% accuracy with preprocessing, evaluation metrics, and visualization in Python. Explored real-world applications in agriculture, urban planning, and surveillance.

Conducted in-depth research on hyperspectral imaging and applied K-Nearest Neighbors (K-NN) for object detection and classification.

●Utilized well-known datasets: Salinas, Pavia University, and Indian Pines for model training and testing.

●Achieved 91% classification accuracy, demonstrating strong performance across multiple HSI datasets.

●Implemented essential data preprocessing techniques including min-max normalization and reshaping for spectral data handling.

●Evaluated model performance using accuracy, F1-score, confusion matrix, and loss vs. accuracy curves.

●Applied the model in Python (Jupyter Notebook) using libraries such as NumPy, Scikit-learn, and Matplotlib.

●Explored practical applications in agriculture, environmental monitoring, urban planning, and military surveillance.

●Gained valuable experience in machine learning, remote sensing, and high-dimensional data analysis.

●Published Project in IEEE(CS 4050)
